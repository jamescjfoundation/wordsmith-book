# Decisions

Decisions about Wordsmith Book's behavior, one file each (`NNNN-title.md`): context, decision,
consequences, and when to revisit. Decisions about shared interfaces, upstream and tooling go in
open-source-core's `docs/decisions/`, never here. From outside this repository a record here is
cited as "Book decision 0003".

Each record's first line gives its date and status, in the form the core's records use. A record
is amended with a dated line or section; its reasoning is never rewritten. A record that no
longer holds says which record replaced it.
