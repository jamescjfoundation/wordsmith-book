## Waiting on a person

- **Requests to Manuscript:** `docs/requests-to-manuscript.md` (moving to the newest core, the contract's
  extra parts, comment anchors, a cover role, editions, raw blocks, a release tag).

- **Print engine (decision 0003):** the embedded typesetting engine at 0.15.1 does not build against
  the core's patched `krilla` and `hayro` (craft-libs' copies). Using it needs a person to move the
  core's patch block or craft-libs' copies, or to carry a fork; until then print is on the core's
  layout.

- **Fixtures:** DOCX, ODT and RTF saved by real word processors, and a DOCX downloaded from an
  online word processor (`docs/fixtures.md`).

- **Golden files:** a look at the print PDFs and EPUBs the golden files in `tests/golden/` stand for
  (`docs/golden.md`, M5.4, M6.3 and M9.4; rewritten since in R2.4, R2.6, R2.10 and R2.14).

- **Layout (R2.4):** on a page that a long footnote mostly fills, the core's layout (WordCraft's)
  can leave a single line of text, because it keeps a note with its reference before widow and
  orphan control; it happens once in Waverley (page 189 in the Classic design). Book cannot change
  the upstream layout; a person may raise it with the core.

- **Hyphenation (R2.13):** the core's print layout (WordCraft's) does not break words at automatic
  hyphenation points in Book's documents at the pinned versions (soft hyphens are honoured), so
  justified lines are looser than they would be. Book's settings ask for it; a person may raise it
  with the core. The stacked-hyphen check is shown with soft hyphens.

- **Release (M9.4):** making the v0.1.0 release is a person's decision: create the repository's
  `release` environment with required reviewers (the publish job waits on it), set the date in
  `CHANGELOG.md`, and push the tag `v0.1.0`. The packages are not signed: signing needs the
  project's certificates. The macOS and Windows packages and the release workflow have not run
  yet (only the Linux package was built and installed here).

- **Reviews:** `docs/SPEC.md` (M0.3); Book's side of the hand-off review, `docs/handoff-review.md` (M1.2). Every [Sourced] rule from a service's public file guide is to
  be rechecked against the current guide, its address added to `.private/sources.md`.

- **Names:** recheck decision 0002's finding that `.wsbk` and `.wsbkz` are free on the three desktop
  platforms before packaging (M9.4).

- **Core:** move Wordsmith Script and Wordsmith Manuscript to the newest core release (core
  v0.1.13 so far; every release in this run is additive). Manuscript's own interface catalog
  (`manuscript-ui::i18n`, Spanish) can move onto the core's `jcj-i18n` then (C4).

- **Interface languages (R2.16):** Book's Spanish catalog (and the shell's, in the core) want a
  native speaker's review. Command replies (also read by agents), preflight findings and build
  messages stay English at 0.2; translating them is a decision for a later release.
