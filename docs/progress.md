This file is a log of what was done. What is planned is the
[`v1` milestone](https://github.com/jamescjfoundation/wordsmith-book/milestone/1) of the issues
(`ROADMAP.md`), and the list "Waiting on a person" at the end is closed: each item still open
is an issue, named there.
**Tests** is the sum of the "passed" counts of every `test result:` line of
`cargo test --workspace` at the end of the step; from 2026-11-27 it is the number of tests
cargo-nextest ran in the gate.

Rows are history and keep what they said; on 2026-11-26 the rows that described one machine's
setup were reworded to say what was checked and with which kind of tool. **Since 2026-11-26**
two things the rows before that date say no longer hold. "The release waits for a person": a person or an agent may release
once the full gate has passed on the commit
([project decision 0002](https://github.com/jamescjfoundation/wordsmith/blob/main/project/decisions/0002-how-changes-land-and-who-releases.md), core decision 0011). "Publishing behind the `release` environment's approval": the
environment takes only `v*` tags and has no reviewers.
