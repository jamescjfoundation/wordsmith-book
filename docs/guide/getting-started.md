# Getting started

A Book project is a folder ending in `.wsbk` (or one packed file ending in `.wsbkz`). It holds
Book's own layer: the design, the editions, front and back matter, fixes and settings. The words
come from a source: a Wordsmith Manuscript project Book reads and never changes, or a source of
the book's own made by importing a file.

1. **Make a book.** From the start window or File › New, choose *From a Manuscript project* to
   link one, or *An empty book* and then **Import a File…** (Mod+Shift+I) for a DOCX, ODT, RTF,
   Markdown or text file.
2. **Look at the outline** (the Outline panel on the left): front matter, the chapters and parts,
   back matter. Add a dedication or an about-the-author page there.
3. **Choose a design** in the Designs panel; each card shows your own first chapter.
4. **Preview**: the Print Preview panel shows spreads; the Ebook Preview panel shows a phone, an
   e-ink reader or a tablet.
5. **Preflight**: the Preflight panel builds an edition and checks it.
6. **Export** from File › Export: the paperback PDF, the EPUB and, if you like, the whole project
   in one file.

**Saving and safety (FIL-1).** Book saves when you ask (Mod+S) and on its own while you work, as
set in Preferences; it keeps packed backups beside the project (`<name> Backups`) and recovers
unsaved work after a crash. **Themes and keys (ACC-1):** light, dark or the system's theme, a
command palette (Mod+Shift+P), key tips (F10) and every command on a key or in the palette (see
[Keys](keys.md)).

**Language.** Book's interface comes in English and Spanish. Choose one in Preferences, under
Language; by default Book follows your computer's language. Preflight findings and messages
from building the book are in English.

**Screen readers.** Every button, field and page in Book has a name a screen reader reads out,
and every command is in the command palette (Mod+Shift+P) and can be given a key.
