# Keys

Made from Book's commands by a test, so it is always current. `Mod` is Ctrl, or the Command key on systems that use it.
Every command, keyed or not, is also in the command palette (Mod+Shift+P).

| Key | Command |
| --- | --- |
| F10 | Key Tips |
| Mod+, | Preferences |
| Mod+F1 | Show or Hide the Ribbon |
| Mod+N | New Book |
| Mod+O | Open… |
| Mod+S | Save |
| Mod+Shift+I | Import a File… |
| Mod+Shift+P | Command Palette |
| Mod+Shift+Z | Redo |
| Mod+W | Close Book |
| Mod+Z | Undo |
